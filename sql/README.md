
# SQL Analysis & Clinical Cohort Extraction

## Overview

This directory contains PostgreSQL SQL scripts developed for the
systematic extraction, transformation, and analysis of synthetic
Electronic Health Record (EHR) data.

The objective is to demonstrate relational database management,
clinical data querying, and population-level analytical techniques
relevant to biomedical research, clinical informatics, and
healthcare data science.

## Analytical Workflow

The SQL scripts are organized into a sequential workflow:

### 01. Database Setup
- Define relational database tables and schemas.
- Establish primary and foreign key constraints.
- Structure patient, encounter, condition, and observation data.

### 02. Data Quality & Validation
- Assess completeness of clinical records.
- Identify duplicate records and missing values.
- Validate relationships between database tables.
- Examine data consistency and integrity.

### 03. Demographic Analysis
- Characterize the patient population by age and sex.
- Examine demographic distributions.
- Aggregate patient characteristics using descriptive statistics.

### 04. Clinical Cohort Extraction
- Identify disease-specific patient populations.
- Extract chronic kidney disease (CKD) cohorts.
- Apply diagnosis-based inclusion and exclusion criteria.
- Explore disease stage distributions where available.

### 05. Comorbidity Analysis
- Identify co-occurring chronic conditions.
- Investigate multimorbidity patterns.
- Examine the relationship between CKD and other
  clinically relevant conditions.

### 06. Healthcare Utilization
- Quantify encounter frequency across patient cohorts.
- Examine healthcare utilization patterns.
- Identify patients with frequent clinical encounters.
- Compare encounter characteristics between cohorts.

## SQL Techniques

The project applies and progressively develops proficiency in:

- Data Definition Language (DDL)
- Data Manipulation Language (DML)
- Filtering and conditional logic
- Aggregate functions and grouping
- Relational joins
- Subqueries and Common Table Expressions (CTEs)
- Date and time operations
- Window functions
- Data quality and validation queries

## Reproducibility

All analytical queries are written for PostgreSQL.

Scripts are documented to support reproducibility,
interpretability, and future extension into Python-based
statistical analysis and visualization.

## Data Governance

All analyses use synthetic patient data generated by Synthea.
No real patient records or protected health information (PHI)
are used in this project.

Clinical coding systems and diagnosis definitions will be
documented according to the source dataset.
